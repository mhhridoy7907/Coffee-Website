# ☕ Coffee Web

A modern and stylish coffee shop website built with **HTML, CSS, and Vanilla JavaScript**, featuring smooth animations, interactive sliders, a 3D coffee carousel, responsive layouts, and a clean user interface.

> 🚀 **Current Development:** The project is now being upgraded from a **static website to a fully dynamic coffee shop platform** with an admin management system and database integration.

![Website Preview](coff.png)

---

## 📅 Upload Date

**02 February 2026**

The original version of Coffee Web was developed as a static front-end project focused on UI design, animations, responsiveness, and interactive JavaScript features.

---

## ✨ Features

### Current Static Version

- Attractive navigation bar with logo and menu
- Animated cover section
- 3D coffee image carousel
- Milkshake horizontal slider
- Drag-to-scroll functionality
- Previous/Next navigation buttons
- Blog slider section
- Product cards with pricing
- Search functionality
- Image preview modal
- Order interface
- Smooth scrolling
- Responsive design for desktop and mobile
- Hidden scrollbars for a cleaner UI
- Smooth hover and interaction animations
- Clean coffee-inspired color palette

---

## 🚀 Dynamic Development

### Dynamic Upgrade Started — 07 October 2026

Today, the project has entered a new development phase:

**Static Website → Dynamic Coffee Shop Platform**

The goal is to make the website content manageable without manually editing the HTML code.

### Planned Dynamic Features

- 🔐 Admin dashboard
- ➕ Add products from Admin Panel
- ✏️ Edit products
- 🗑️ Delete products
- 🖼️ Upload product images
- ➕ Add and manage blogs
- ✏️ Edit blog information
- 🗑️ Delete blogs
- 🖼️ Manage 3D carousel images
- 📦 Customer order management
- 🔄 Dynamic product rendering
- 🔍 Dynamic search
- 📊 Admin dashboard statistics
- 💾 Database-based content management
- 🔥 Firebase integration
- 🔐 Secure admin authentication
- ☁️ Firebase Storage for image uploads

> **Development Goal:** Transform Coffee Web from a front-end static project into a complete, database-powered coffee shop web application.
